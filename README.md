## Description
A REST API for managing students.

## Features
- Create students
- Get all students
- Get a single student
- Update students
- Delete students

## API Endpoints

POST /students

GET /students

GET /students/:id

PUT /students/:id

PATCH /students/:id

DELETE /students/:id

## How to Run

Install dependencies:

npm install

Start server:

npm start

node src/server.js
